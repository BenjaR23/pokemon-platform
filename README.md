# Pokémon Platform

Full-stack web application for managing a personal Pokémon collection and planning Pokédex completion.

## Status

Early development.

## Architecture

- Frontend: React + Vite + TypeScript
- Backend: NestJS + Node.js + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Testing: Jest, Supertest and Playwright
- Infrastructure: Docker
- CI/CD: GitHub Actions
